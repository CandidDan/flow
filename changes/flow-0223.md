- **PRs that change only tasks, intents, workstreams or research run minimal CI, and flow-doctor
  warns about push-to-main workflows that run on every task commit** (`.github/workflows/_flow-gates.yml`,
  `.github/workflows/_flow-review.yml`, `project-template/.flow/bin/flow-review.mjs`,
  `project-template/.flow/bin/flow-doctor.mjs`, `project-template/.flow/config.yml`, flow-0223). A
  store-only PR — every changed file matches `minimal_ci.paths` in the base branch's config — now
  runs only the store-guard and flow-doctor in the gate, and qa, code-review and security each pass
  it with a fixed line and call no model. Files under `.flow/` outside the stores, `.github/`,
  `.claude/`, `CLAUDE.md` and `AGENTS.md` always get the full gate. An intent-only PR is gated the
  same way and keeps its advisory intent reviewer and its security review.

  **Caller action:** none for the PR behaviour — adopters get it at the next sync with no edit, using
  the default paths (`.flow/tasks/**`, `.flow/intents/**`, `.flow/workstreams/**`,
  `docs/research/**`). A repo that keeps research outside `docs/research/` adds its folder to
  `minimal_ci.paths` in `.flow/config.yml`. Act on any new flow-doctor warning naming a workflow by
  adding `paths-ignore: [".flow/tasks/**", ".flow/intents/**", ".flow/workstreams/**", "docs/research/**"]`
  (or a `paths:` filter) to its `push` trigger, or by listing it in
  `minimal_ci.push_workflows_exempt` with the reason it must run on a state commit.
