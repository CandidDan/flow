- **The PR gate's three bookkeeping jobs are one job, so each gate run bills ~2 fewer minutes**
  (`.github/workflows/_flow-gates.yml`, flow-0137). GitHub bills every job at least one minute,
  and `touches`, `flow-tooling` and `source-roots-plan` each did a few seconds of work. The
  touches-guard and its assertion, the flow-tooling tests, flow-doctor and the source-roots plan
  are now steps in `source-roots-plan`. Each still fails the run by itself, and each runs after
  an earlier one fails, so no verdict is hidden. `source-root` still reads its matrix from that
  job and still does not wait on `gate`. **Caller action — only if branch protection requires
  these checks:** the checks `flow-gates / touches` and `flow-gates / flow-tooling` stop
  reporting. A ruleset or branch-protection rule that names either one would block every PR on a
  check that never arrives. In Settings → Rules (or Branches), replace both with
  `flow-gates / source-roots-plan`. The caller files do not change. A repo that requires only
  `flow-gates / gate`, or nothing, has nothing to do.
