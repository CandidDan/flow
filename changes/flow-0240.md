- **The review checks install Claude Code from npm, not from `claude.ai`** (`.github/workflows/_flow-review.yml`, `_flow-kickback.yml`, `_flow-pr-text.yml`, flow-0240). **No caller action**: callers reference the reusable workflows, so the fix arrives with the next pinned release. A self-hosted runner now needs to reach `registry.npmjs.org`.

  `claude-code-action` downloaded the CLI from `claude.ai/install.sh` on every job. On self-hosted runners that share one public IP, that download answered 403 to about 1 job in 9, and the check failed before any review ran. Each job that runs the action now installs `@anthropic-ai/claude-code` at the version in `env.FLOW_CLAUDE_CODE_VERSION` (2.1.293, the version the pinned action installs) and passes it through `path_to_claude_code_executable`. If the npm install fails, the action falls back to its own download. A test ties the version to the pinned action SHA; `docs/flow-reusable-workflows.md` says how to bump both.
